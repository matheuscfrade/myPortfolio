# Admin Local

Esta pasta contem a interface administrativa local.

Quando o servidor estiver rodando:

- Admin: `http://127.0.0.1:5000/admin/`
- Portfolio publico local: `http://127.0.0.1:5000/portfolio/`

## Recursos

- importar PDFs;
- copiar PDFs em massa para `Documentos/` e sincronizar;
- editar metadados;
- criar categorias;
- ocultar documentos;
- personalizar nome, subtitulo e titulo do site;
- gerar pacote publico para hospedagem estatica.

O Admin e uma ferramenta local. Ele nao deve ser publicado junto com o site publico.
