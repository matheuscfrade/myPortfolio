Como funciona

O app separa o trabalho privado de organização da página estática que pode ser publicada para outras pessoas.

1. Admin local

Abra o painel no Windows, importe PDFs, crie categorias e ajuste os dados sem enviar nada para a nuvem.

2. Revisão de metadados

Confira nome, assunto, número, data, categoria e visibilidade antes de liberar qualquer documento.

3. Site público

Gere uma pasta estática com a visualização pública, os dados publicados e os PDFs visíveis.

Carga inicial em massa

Para começar com uma coleção grande, copie os PDFs para a pasta Documentos do aplicativo e sincronize a estrutura inicial no Admin.

1Localize Documentos

Abra a pasta de dados do aplicativo e entre em Documentos.

2Copie PDFs

Adicione vários arquivos de uma vez, se quiser organizando como Categoria/Ano.

3Sincronize

O app lê a pasta, atualiza a lista e prepara os cards para revisão.

4Revise

Ajuste metadados e visibilidade antes de publicar a versão externa.

Copiar PDFs para Documentos não finaliza o cadastro. Depois de sincronizar, revise nome, assunto, data, categoria e visibilidade no painel Admin.

Publicação na Web

O app local não torna nada público sozinho. A publicação acontece somente quando você envia os arquivos estáticos gerados para uma hospedagem.

O painel Admin fica no seu computador. Para publicar de verdade, revise os documentos, clique em Gerar pacote público no Admin e envie apenas os arquivos estáticos da pasta dist-publico para Cloudflare Pages, Netlify, GitHub Pages ou Vercel.
